# Linux Commands

- `whoami`	Current username

- `id`	User ID and group memberships

- `groups`	Groups your user belongs to

- `chown`	Change file ownership

- `chgrp`	Change group ownership

- `sudo`	Execute a command with elevated privileges

- `pgrep -a` Searches for running processes matching a name or pattern

- `ps aux` Displays processes from all users, including information about CPU and memory usage

- `ps -ef --forest` Displays processes in a tree-like structure, showing which processes started other processes
